## 1. Product Goal & Architectural Contract

Portakal 1.1 introduces the **Preview-Before-Print Architecture**:

```dart
// 1. Resolve once
final ResolvedLabel job = builder.resolve();

// 2. Preview the exact resolved job
LabelPreview.resolved(job: job);

// 3. Compile that exact SAME resolved job for hardware
final Uint8List bytes = tsc.compileResolved(job);
```

### Key Guarantees
- **Same-Job Identity**: `compile(builder) == compileResolved(builder.resolve())`. Preview and compilers consume the identical logical AST.
- **Platform Independence**: Pure-Dart canonical intermediate representation (`PreviewScene`) rendered identically in SVG (`renderPreviewScene`) and Flutter Canvas (`LabelPreview.scene`).
- **Zero Byte Regression**: Compiler printer output streams for all 9 protocols remain 100% frozen and byte-identical to the 1.0.0 hardware golden baseline.

## 6. GitHub Actions CI Repair & Root Cause Analysis

### Diagnosis
1. **Core Jobs Exit 69**:
   - `core-minimum` and `core-stable` previously executed `dart-lang/setup-dart@v1` (standalone Dart SDK, no Flutter SDK).
   - In a pub workspace containing Flutter packages (`packages/portakal_flutter` and `example`), `dart pub get` attempts to resolve `sdk: flutter` for all workspace members.
   - Without the Flutter SDK installed on the runner, Dart pub exited with code 69 (`EX_UNAVAILABLE: Flutter SDK not found`).
2. **Flutter Minimum Exit 1**:
   - `flutter-minimum` executed Flutter 3.27.0 (bundling Dart 3.6.0).
   - `packages/portakal_flutter` and `example` specified `flutter_lints: ^6.0.0` (which requires Dart $\ge 3.8.0$).
   - Version solving failed on the minimum SDK runner.

### Resolutions Applied
- Replaced `dart-lang/setup-dart` with `subosito/flutter-action@v2` across all jobs so the complete monorepo workspace can be resolved via `flutter pub get`.
- Adjusted dev dependencies to `lints: ^5.0.0` in `portakal_core` and `flutter_lints: ^5.0.0` in `portakal_flutter` and `example`, restoring full resolution compatibility with Dart 3.6.0 and Flutter 3.27.0.
- Added explicit SDK version logging (`dart --version` and `flutter --version`) to every CI job.
- Added dedicated `format` job for repository-wide `dart format --output=none --set-exit-if-changed .`.

## 7. Known Limitations & Explicit Boundary

1. **Code 128 Code Sets**: Only Code Set B is rendered visually. Set A/C or dynamic code switching safely falls back to diagnostic placeholders.
2. **UPC-E**: Zero-suppressed expansion is classified as placeholder for 1.1 and will be expanded in a future release.
3. **Printer ROM Fonts**: Renderers approximate layout using monospace/sans-serif fonts; firmware-specific non-proportional bitmap glyphs are not emulated pixel-for-pixel.
4. **Thermal / Mechanical Physics**: Print head heat accumulation, burn times, and physical paper feeding jitter are outside SDK scope.
